## Vision

### 10x Check
The 10x version isn't just "migrate X lists" — it's any social graph migration between any platform.
Source adapters (X list, X following, Bluesky, Mastodon, CSV) × Destination adapters (X follow, X list,
Bluesky follow, CSV export). One command migrates your entire network when a platform implodes.
The X→X case is the first of many.

### Platonic Ideal
`pip install x-migrate`. First launch runs a wizard. Live TUI shows progress bar, follow count,
rate-limit status, ETA. `--dry-run` previates who'd be followed. Results exportable to CSV.
A non-technical user can run it.

## Accepted Scope
- Proper CLI package: `x-migrate extract / follow / report / setup`
- Extract from X List OR X Following (public accounts)
- Follow or add-to-list as destination mode
- Rich TUI with live progress, ETA, rate-limit status
- --dry-run flag on follow command
- PyPI packaging with pyproject.toml + entry point
- ~/.x-migrate.toml config file + `x-migrate setup` wizard
- Unified progress store (single JSON format)
- Browser profiles stored in ~/.x-migrate/ not working dir
